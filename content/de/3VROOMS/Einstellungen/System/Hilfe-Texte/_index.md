Im linken Sidepanel finden Sie unter _Hilfe-Texte_ den Button _Bearbeitungsmodus aktivieren_ oder _Bearbeitungsmodus deaktivieren_, wenn dieser bereits aktiv ist.

Bearbeitungsmodus aktivieren

* Klick auf Button
* Button wechselt die Beschriftung auf _Bearbeitungsmodus deaktivieren_
* Edit Modus ist aktiv

### Ansicht der Hilfetexte in Rooms


Überall in der Applikation wird im Sidepanel, Inhaltsbereich und View Mode vor einem Label (Beschriftungsfeld) ein Hilfe Icon eingeblendet. Wo ein Hilfetext in der Sprache des angemeldeten Benutzers hinterlegt wurde, wird das Hilfe Icon eingeblendet.


Klicken Sie auf das Icon, öffnet sich ein Popup mit dem Namen des Felds als Titel. Pro aktivierte Sprache wird ein mehrzeiliges Eingabefeld angezeigt - keine Pflichtfelder. Klicken Sie auf Speichern und die Hilfetexte werden gespeichert. Schliessen Sie anschliessend das Popup.
