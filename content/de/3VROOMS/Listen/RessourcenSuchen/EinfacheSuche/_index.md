Um eine Ressource zu finden, navigieren Sie im Sidepanel auf das fünfte Subpanel mit dem Namen _Ressourcen_. Dadurch öffnet sich die Suchmaske.

{{< imgproc List_RES_EinfSuch Resize "320x" >}}
Suchmaske für Ressourcen im Sidepanel
{{< /imgproc >}}

Folgende Tabelle erläutert die Eingabefelder:

{{< bootstrap-table "table table-striped" >}}
|Feld||Funktion|
|---|---|---|
|Ressourcenart|| Wählen Sie aus dem Drop-Down-Menü die gesuchte Ressourcenart aus. Die Ressourcenarten sind firmenspezifisch definiert.|
|Standort||Geben Sie den Standort der Ressource ein oder wählen Sie diesen über die Schnellauswahl aus.|
{{< /bootstrap-table >}}
